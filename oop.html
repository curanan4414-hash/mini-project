💼 Payroll System

แดชบอร์ด + เพิ่มพนักงาน 🔍 สรุปหลักการ OOP

🎓 สรุปการประยุกต์ใช้ 4 เสาหลักของ OOP

ระบุตำแหน่งคลาสและบรรทัดที่ใช้ในไฟล์ app.js ตามเกณฑ์การประเมิน

📌 จำนวนคลาสที่ออกแบบเอง (ครบ 5 คลาส):

1. Employee (Abstract Base Class)

2. FullTimeEmployee (สืบทอดมาจาก Employee)

3. PartTimeEmployee (สืบทอดมาจาก Employee)

4. ContractEmployee (สืบทอดมาจาก Employee)

5. PayrollManager (คลาสจัดการฐานข้อมูลและการคำนวณงบประมาณ)

1. Encapsulation (การห่อหุ้มข้อมูล)

ซ่อนฟิลด์ภายในด้วย Private Fields (#id, #name, #salary)[cite: 5]

app.js บรรทัด 5-7, 16-18

2. Abstraction (การซ่อนรายละเอียด)[cite: 5]

กำหนดเมธอดต้นแบบ calculateSalary() ในคลาสแม่ บังคับให้คลาสลูกต้องมีฟังก์ชันนี้

app.js บรรทัด 22-24

3. Inheritance (การสืบทอด)[cite: 5]

ใช้ extends Employee และ super(id, name) ส่งต่อคุณสมบัติพื้นฐาน[cite: 5]

app.js บรรทัด 38, 64, 91

4. Polymorphism (พหุสัณฐาน)[cite: 5]

คลาสลูก Override สูตร calculateSalary() ต่างกัน และเรียกคำนวณผ่าน Loop เดียว[cite: 5]

app.js บรรทัด 46, 73, 100, 161
